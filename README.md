## 怎么用

1. 在下方表格里新增一行。
2. **单词**：要记的词（可带词性）。
3. **释义**：中文或英文释义，尽量短。
4. **助记句**：自己编一句，把这个词用进去；句子越贴自己的生活越好记。
5. **备注**（可选）：近义词、易混点、出处等。

## 小提示

- 助记句尽量用自己会说的话，不要抄词典例句。
- 同一词可多写几句，换场景记更牢。
- 复习时先遮住释义，只看助记句猜词义。

## 部署（Netlify）

1. 继续只改本文件（`README.md`）记单词即可；首页 `index.html` 会自动渲染它。
2. 把项目推到 GitHub 后，在 Netlify 里 Import 仓库；或把整个文件夹拖到 [Netlify Drop](https://app.netlify.com/drop)。
3. 构建设置：Publish directory 为 `.`（已写在 `netlify.toml`），无需 Build command。
